3 · 本地版 SwissBioisostere 设计（核心）

3.1 原理对齐（为什么能复现）

SwissBioisostere 不是黑箱：它的数据来自 ChEMBL 的 MMP（matched molecular pairs）——同一 assay 内成对的化合物，共享一个「恒定部分」，在一个「R 基片段」上不同；把成千上万个这样的替换聚合，就得到「某片段 → 替换片段」的库，并统计每个替换的平均 ΔlogP/ΔtPSA/ΔMW、出现次数、以及按生物活性变化分三类的 #Better/#Similar/#Worse（阈值 Δbioactivity ≥ 0.5 log 判为更好/更差，其余 Similar）。只要我们能从 ChEMBL 复现 MMP 抽取，就能本地得到同构的库。

3.2 分层数据策略（按忠实度递进）

层做法忠实度 / 成本用途
L0 规则库medchem 等排规则（环↔环、官能团↔官能团：苯↔噻吩/呋喃/吡咯/吡啶、-OH↔-NH₂↔-F、-COOH↔四唑…）+ RDKit 现算 Δ 属性低忠实 / 极快当天可跑通的 MVP，先验证 B–G 链路
L1 mmpdb + ChEMBL用开源 mmpdb 对 ChEMBL 结构枚举 MMP，建「fragment → replacements」索引；统计 Δ 属性、频次；活性维度可选从 ChEMBL activity 表补高忠实 / 重（全量 ChEMBL 建库按小时计）真正的复刻，对标 1663 候选
L2 改进在 L1 上加：ΔHAC/Δ环数/ΔHBD·HBA/ΔRotB、SA-score 可合成性、3D 形状相似（USR/Overlap）、可选的靶点/口袋感知加权超越官方「更优」的论据

3.3 统一接口与输出

engine(query_fragment: str,            # 带 [*:1]/[*:2]/[*:3] 的片段或母核 SMILES
       source: "L0"|"L1"|"L2",        # 数据层
       filters: dict,                 # ΔlogP/ΔtPSA/ΔMW 区间（对齐 notebook）
       topn: int) -> DataFrame        # 列与 SwissBioisostere 完全一致

输出严格复刻官方 CSV 列：Candidate Fragments, Frequency, #Better, #Similar, #Worse, Δ logP, Δ tPSA, Δ MW（含 \xa0 列名兼容），这样 run_fraggen 的 SwissBioisostereo_filter() 无需改动即可读本地结果。

3.4 关键算法点

  • MMP 抽取：mmpdb 按单键切分 + 环境匹配；记录 attachment point 与「恒定部分」。
  • 按查询片段聚合：给定 query 片段，匹配所有「被替换片段 = query」的 MMP，收集其替换片段（不要求恒定部分相同——与官方「查某片段的所有历史替换」一致）。
  • Δ 属性：默认 RDKit（Crippen logP / TPSA / ExactMolWt）计算；为对齐官方口径，可选读 ChEMBL 提供的 ACD logP / tPSA / MW（建库时一起入库）。
  • Better/Similar/Worse：有 ChEMBL 活性时按 Δbioactivity 0.5 log 阈值分三类；无活性时置空并在报告标注「降级」。
  • 评分与排序：频次 + 属性相似度（复刻官方 success score 思路）→ 可叠加 L2 指标。

3.5 对标测试协议（判定「相同 / 更优」）

基准：query [*:1]c1cc2ccccc2o1，官方 1663 候选 CSV。
指标（L1 对官方；L2 对 L1）：
① Top-N 召回：官方 Top-20/50/100 中被本地命中的比例（期望 L1 ≥ 80%）；
② 排序一致性：候选频次/排名的 Spearman ρ；
③ Δ 属性一致性：重合候选的 ΔlogP/ΔtPSA/ΔMW 之 MAE（期望 < 0.5 log / < 10 Å² / < 10 Da）；
④ 覆盖度：本地在官方之外的候选数，且经 RDKit 合法性 + 属性过滤仍有效（「更优」的证据之一）；
⑤ 效率：单查询耗时、建库耗时/体积。
判定：L1 达 ①≥80% & ③达标 = 「功能相同」；L2 在 ④ 有质的增量且不损 ①③ = 「更优」。

7 · 风险与对策

风险对策
ChEMBL 全量 MMP 建库耗时/占空间先子集（如目标相关或随机 20–50 万化合物）跑通，再扩全量；D 盘空间充足（3.2 TB）
「更优」判定主观先用 3.5 的量化指标定基线；L2 增量单列，不与 L1 混判
8 GB GPU 对接批量受限分批 + 并发受控 + 失败重试；必要时降 box/分批
KCOMBU / PDBQT 工具链缺失S0 内编译 fkcombu；PDBQT 用 Meeko 绕开 py2
数据口径不一致（ChEMBL 版本、logP 来源）建库锁定 ChEMBL 版本（建议与 chembl22 同代以便同口径），属性来源写入 provenance
官方库不可下载 → 无法逐条 1:1 复刻以「Top-N 召回 + 属性一致性 + 经典等排覆盖」作为等效判据，而非逐行比对
